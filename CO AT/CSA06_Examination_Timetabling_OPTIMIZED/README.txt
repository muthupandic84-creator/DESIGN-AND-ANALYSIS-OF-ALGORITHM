CSA06 – Examination Timetabling Assignment Package

Files:
- CSA06_Examination_Timetabling_Report.docx: assignment report.
- timetable_solver.py: backtracking feasibility solver and optimal timetable output.
- README.txt: run instructions.

Run in VS Code terminal:
    python timetable_solver.py

The program prints a feasible timetable and then the optimised timetable.
The optimal same-day clash penalty for the supplied data is 3.

DAA ASSIGNMENT 4 – PART II (Python)
====================================

Files:
1. task1_word_wrap.py       Dynamic Programming word wrap, DP trace, 3 widths, boundary test
2. task2_knapsack.py        Fractional greedy and 0/1 DP with a counterexample
3. task3_graph_algorithms.py Dijkstra, Bellman-Ford, negative-cycle detection, Floyd and Warshall
4. task4_assembly_line.py   Assembly-line DP, route reconstruction, disruption experiments
5. task5_mst.py             Kruskal, Prim and Boruvka with edge-selection traces
6. task6_tsp.py             Held-Karp TSP, exhaustive validation and state-growth observations

How to run:
Install Python 3.8+ (no external packages required), open a terminal in this folder, and run:
python task1_word_wrap.py
python task2_knapsack.py
... and so on.

Important:
- The scripts contain reproducible sample inputs and print intermediate evidence.
- Replace sample datasets with your own test data if your instructor expects student-created inputs.
- Capture terminal screenshots for each task.
- Task 1 uses squared unused spaces for each non-final line, and zero penalty for the final line.
- Graph algorithms use directed edges as entered.
- TSP input is a symmetric cost matrix with hub at index 0.
